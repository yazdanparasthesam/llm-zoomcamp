📡 ComplaintRadar

End-to-end CFPB consumer-voice RAG (not SEC 10-K filings).

This Vercel page is the Terraform-provisioned cloud landing. The interactive Streamlit app (hybrid search, agent tools, audio briefings, Grafana) is a long-running service — deploy it with render.yaml or fly.toml and put the live URL in the project README.

  • Dataset: public CFPB complaint narratives
  • Ingestion: dlt + Module 07 chunking
  • Retrieval: BM25 (eval winner), hybrid RRF, re-rank, query rewrite
  • Monitoring: PostgreSQL + 6-chart Grafana
